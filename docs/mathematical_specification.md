# Mathematical specification

Vertices A=(1/2,sqrt(3)/2), P=(0,0), R=(1,0). Raw scores s_i >= 0 with sum > 0 normalize to w_i=s_i/sum(s), yielding sum(w)=1. The Cartesian point is w_A A + w_P P + w_R R. Midpoints create four congruent subtriangles, each with one-quarter the original area. The names Theory, Evidence, Interpretation and Explanation are interpretive conventions, not theorems. Rotations and translations preserve Euclidean lengths and area; they do not prove semantic correspondence. Normalization discards magnitude. Axis independence and empirical score validity are untested.
